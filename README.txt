WHAT IS IN THIS FOLDER

TO SEE THE SITE ON YOUR OWN COMPUTER
------------------------------------
Double-click index.html. It opens in your browser. Nothing is
published yet — only you can see it.


TO PUT IT ON THE INTERNET (about 10 minutes)
--------------------------------------------
1. Go to  app.netlify.com/drop
2. Drag this whole folder onto the page.
3. Wait about 20 seconds. You get a web address you can share.
4. Create a free account when prompted, so the site stays up.
5. In Site settings, change the site name to something sensible,
   e.g.  tsra-learners-cove.netlify.app

TO USE A SCHOOL ADDRESS INSTEAD
-------------------------------
Ask school IT to add one DNS record:
    Type:  CNAME
    Name:  library
    Value: <your-site-name>.netlify.app
Then in Netlify: Domain settings > Add custom domain >
    library.tsrahyderabad.com
The secure padlock (HTTPS) is switched on automatically.

TO UPDATE THE SITE LATER
------------------------
Edit the files, then drag the folder onto Netlify again.
The new version replaces the old one within a minute.
